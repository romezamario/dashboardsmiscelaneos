# Dashboards misceláneos

Colección de páginas estáticas (HTML + JS, sin backend). Se pueden abrir con cualquier servidor estático
o publicar con GitHub Pages.

| Dashboard | Descripción |
|---|---|
| [`huracanes-sucursales/`](huracanes-sucursales/) | Sucursales Banamex vs huracanes activos: mapa, cono de pronóstico y ranking de exposición. |

Para verlas en local:

```bash
python3 -m http.server 8000
# abrir http://localhost:8000/huracanes-sucursales/
```
